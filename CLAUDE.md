# CLAUDE.md

Guidance for Claude (and humans) working in this repo. Read this before touching code.

## Project overview

Personal portfolio of **Rashad Hussein**, a freelance full-stack developer. It is a single-page, heavily animated site:
loader, hero, services, marquee, selected works, about, testimonials, contact and footer.

- Live: https://portfolio-2026-rosy-sigma.vercel.app/ (canonical domain in metadata: `https://www.rashadhussein.com/`)
- Repo: https://github.com/Rashadhusien/portfolio-2026
- Origin: a Next.js port of hetari's Vue portfolio (UI design by Huy Nguyen). Keep the attribution in `README.md`.

**Visual identity (do not replace, only enhance):** off-white `flax-smoke-50` page with near-black `#0B0B0A` panels,
the `flax-smoke-*` olive-grey palette, bold grotesk type (Cabinet Grotesk as `font-title`, Bricolage Grotesque as
`font-fancy`), and the fixed SVG grain overlay in `AppShell`.

## Git workflow (hard rules)

1. **Never commit or push directly to `main`.** `dev` is merged into `main` only by the owner, manually.
2. All work branches are cut from `dev`:
   - `feature/<short-name>`: new sections or animations
   - `fix/<short-name>`: bugs
   - `chore/<short-name>`: config, deps, docs, tooling
3. Every branch goes back into `dev` through a PR (`--base dev`). One concern per branch.
4. Commits use **Conventional Commits**: `feat:`, `fix:`, `chore:`, `refactor:`, `perf:`, `docs:`, `style:`.
   Example: `fix(works): wrap project tags on long titles`.
5. Local guard: `.githooks/pre-push` rejects any push to `refs/heads/main`. Enable it once per clone:
   ```bash
   git config core.hooksPath .githooks
   ```
   Owner override for the manual release: `ALLOW_MAIN_PUSH=1 git push origin main`.

### Merging stacked work

Phase 1 branches were cut before anything was merged, so `chore/phase-1-integration` merges all of them; later
branches stack on it. Merge the integration branch (or each Phase 1 PR, in its listed order) into `dev` first.

## Code conventions

- **Components:** function components, named exports (`export function Hero()`), one component per file, PascalCase
  filenames. Add `'use client'` only when the file uses hooks, GSAP or browser APIs.
- **Placement:** page sections in `components/sections/`, decorative/animated pieces in `components/design/`,
  generic UI in `components/common/`. Content lives in data files, not inline in JSX.
- **Imports:** use the `@/` alias (`@/components/...`, `@/lib/...`).
- **Types:** `type` aliases for props (`type HeroProps = {...}`), no `any`.
- **Tailwind:** use the theme tokens (`flax-smoke-*`, `heading-1`…`heading-6`, `heading-display`, `padding-x`,
  `common-padding`, `flex-center`, breakpoints `2xs/xs/…/4xl`). Add new tokens/utilities in `globals.css` via
  `@theme`/`@utility`, not arbitrary one-off hex values. Prettier's Tailwind plugin sorts classes.
- **Images:** always `next/image` with real `width`/`height` (or `fill`) **and** a `sizes` prop; `priority` only for
  the LCP image. Videos: `muted playsInline loop`, `preload="none"` or `metadata`, a `poster`, and `.webm` + `.mp4`
  `<source>`s.
- **IDs vs refs:** existing code targets elements by global IDs (`#hero`, `#index`…). New code should use refs and
  `useGSAP({ scope })` instead of global selectors.

## Animation rules

- **Single registration point:** import `gsap`, `ScrollTrigger`, `useGSAP` (and `CustomEase`) from `@/lib/gsap`,
  never from `gsap`/`@gsap/react` directly. Do not call `gsap.registerPlugin` anywhere else, and never import
  `gsap/all`. The house ease is `'expo'`.
- **Lenis ↔ ScrollTrigger sync:** one Lenis instance driven by `gsap.ticker` and
  `lenis.on('scroll', ScrollTrigger.update)`, with `gsap.ticker.lagSmoothing(0)`. No second `requestAnimationFrame` loop.
- **Scrolling:** lock/unlock only via `setScrollLocked()`; programmatic scrolls via `scrollToTarget()` (works when
  Lenis is off). The page starts locked (`stop-scrolling` on `<body>`) and the preloader unlocks it.
- **Cursor:** mark elements with `data-cursor="view|link|hidden"`; links/buttons get `link` automatically. Wrap
  interactive elements in `<Magnetic>` (child `data-magnetic-inner` for parallax) instead of hand-written magnets.
- **Cleanup:** every animation lives inside `useGSAP(() => {...}, { scope: ref, dependencies: [...] })` or a
  `gsap.context()` that is reverted on unmount. Event listeners added inside must be removed in the returned cleanup.
- **Reduced motion:** check `useMotionPrefs().reduced` / `prefersReducedMotion()` (or `gsap.matchMedia()`); content must be fully visible
  and readable with no motion (no element may stay at `opacity: 0` / `translateY(100%)`). Lenis is disabled too.
- **Mobile:** heavy effects (WebGL, custom cursor, magnetic, pinned horizontal scroll, velocity skew) are disabled
  below `md` (768px) and on touch devices (`(hover: none)`).
- **60fps:** animate only `transform` and `opacity` (plus `clip-path` when needed). Never animate
  `width/height/top/left/margin/filter` per frame. Use `gsap.quickTo`/`quickSetter` for pointer-driven values,
  `will-change` only while animating.
- **Tailwind translate gotcha:** classes like `translate-y-full` set the CSS `translate` property. On HTML elements
  `gsap.to(el, { y: 0 })` works; on **SVG** elements GSAP mis-reads it, so tween `'--tw-translate-y'` instead.
  Avoid zero-duration tweens of CSS variables (use `0.001`).
- **Text splitting:** go through `SplitText` (the component). Real space characters must exist between words and the
  container carries an `aria-label` with the full sentence; letters are `aria-hidden`.

## Performance budget

- Lighthouse (mobile, production build) ≥ **90** in Performance, Accessibility, Best Practices and SEO.
- LCP < 2.5s, CLS < 0.1, INP < 200ms.
- WebGL / three.js / OGL is loaded only through `next/dynamic(() => import(...), { ssr: false })`, mounted when in
  view, and skipped on mobile/reduced-motion. No 3D library in the initial bundle.
- No new dependency over ~30 KB gzipped without a note in the PR explaining why.
- Large media: videos lazy (`preload="none"` + IntersectionObserver), images sized with `sizes`.
